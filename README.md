# AI Movie Recommendation Bot

Telegram-бот для подбора фильмов и сериалов по запросу на естественном языке.

**Стек:** Telegram Bot API → Kinopoisk Dev API → GigaChat (парсинг текста) → форматированный ответ.

---

## Возможности

- **🎬 Подборки** — готовые списки с выбором жанра и листанием карточек
- **Текстовый поиск** — свободный запрос на русском языке
- **/filters** — расширенный пошаговый подбор (жанр, годы, страна, тип, студия)
- Исключение мультфильмов, документального, концертов, ток-шоу
- Рейтинг Kinopoisk не ниже 6.0 в подборках
- Прямые ссылки и постеры из Kinopoisk

---

## Подборки

После нажатия **🎬 Подборки**:

1. Выберите тип подборки (новинки, популярное, рейтинг, случайный фильм)
2. Выберите приоритетный жанр или **🎭 Любой жанр**
3. Бот покажет **одну карточку** с постером, рейтингом и описанием
4. Листайте фильмы кнопками **⬅ Предыдущий** / **➡ Следующий** / **🎲 Другой случайный**

Запрос к Kinopoisk выполняется один раз; дальше бот переключает уже загруженный список без новых сообщений в чате.

## Быстрый старт

### Локально

```bash
python -m pip install -r requirements-dev.txt
cp .env.example .env   # заполните BOT_TOKEN, KINOPOISK_API_KEY, GIGACHAT_AUTH_KEY
python main.py
```

### Docker

```bash
cp .env.example .env
docker compose up --build
```
