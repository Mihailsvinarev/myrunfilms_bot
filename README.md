# 🎬 AI Movie Recommendation Bot

AI Telegram bot that recommends movies based on natural language input using:

- 🧠 LLM (Ollama)
- 🔎 Semantic search (embeddings)
- 📦 Vector database (ChromaDB)
- 🤖 Telegram Bot API

---

## 🚀 Features

- Natural language movie search
- Semantic understanding of user mood
- AI-powered explanations
- Movie recommendations from MovieLens dataset
- RAG architecture (Retrieval-Augmented Generation)

---

## 🧠 Architecture

User → Telegram Bot → AI Agent → Embeddings → ChromaDB → LLM → Response
